## 1. 核心结论

**已验证：在固定KDA权重、奖励、动作、时序结构和安全规则的条件下，将部署期固定前5人替换为现有TTC Top-5，在独立确认集上提高成功率并降低碰撞。**

| KDA，独立确认3000例 | 固定前5人 | TTC Top-5 | 差值 |
|---|---:|---:|---:|
| 成功率 | 84.83% | 90.27% | +5.43pp，净增加163次成功 |
| 碰撞率 | 12.07% | 7.17% | -4.90pp，减少147次碰撞 |
| 超时率 | 3.10% | 2.57% | -0.53pp，减少16次超时；下降未达校正后显著 |
| 平均原始折扣回报 | 0.438162 | 0.494118 | +0.055956 |

成功率和碰撞率差异通过本轮预先冻结的6项Bonferroni校正；成功率的case-cluster 95%区间为[+3.97,+6.90]pp，family级区间为[+3.53,+7.37]pp。

**这证明部署期行人选择有真实系统增益，不证明KDA记忆能力独有，也不证明KDA优于Mamba。GRU同样获得改善，且本轮未测Mamba。**

TTC Top-5使用继承公式对全部N人评分后截断，不发明新的风险度量：

```text
distance = sqrt(rel_x^2 + rel_y^2 + 1e-6)
closing = -(rel_x*rel_vx + rel_y*rel_vy) / (distance + 1e-6)
score = distance/(closing + 1e-6) if closing > 0.1 else distance*10
select argsort(score)[:5]
```

它是原系统的距离/接近速度代理，不是严格考虑半径、侧向错过距离的碰撞TTC，也没有“理论上必然优于最近5人”的保证。

## 10. 裁决与证据分层

| 层级 | 结论 |
|---|---|
| 已验证 | 仅换选人规则、相同KDA权重，在fresh独立确认集提高SR并降低CR，满足冻结的KDA总体采用门槛 |

| 未证明 | TTC稳定优于最近5人；跨训练seed稳定性；KDA特有记忆贡献；相对Mamba优势 |

总体采用门槛不是每格安全非劣门槛：本轮通过的是预先定义的KDA总体SR显著改善且CR/TO计数不增加，不得把局部退化隐藏掉。
